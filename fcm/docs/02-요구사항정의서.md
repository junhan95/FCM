- ✅ **겸직 가능** — 한 사람이 여러 사업장 권한을 보유할 수 있으나, 세션당 활성 사업장은 1개

**미결 사항**
- 사업장 **내부**에서 동료의 담당 고객을 조회할 수 있는가 → 현재 "사업장 전체 공유"로 가정. 이것이 아니면 사업장 내 중복 영업도 해결되지 않음
- 계정 발급·권한 부여 주체 → **잠정 결정**: 신원 계정 생성·비활성화는 System Admin, 사업장 권한 부여·회수는 해당 사업장 Site Admin. 확인 요망
- 동시 세션 정책 → **잠정**: 계정당 1개(새 로그인 시 기존 세션 폐기). 겸직자가 두 사업장을 동시에 봐야 하는 업무가 있는지 확인 필요
- E-17 퇴사자 처리는 기획안 문제 #4("퇴사 시 연락처 소실")의 직접 대응 요소
